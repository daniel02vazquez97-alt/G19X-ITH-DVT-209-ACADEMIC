# Guía sintética de datos

## Fuentes de cifras

Las cifras de inventario y abastecimiento proceden de datos estructurados y de cálculos persistidos por el sistema. El contenido documental aporta contexto, pero no es la fuente de una cantidad, un punto de reorden ni un stock de seguridad.

## Resultados

Una recomendación puede sugerir pedir, indicar que no hace falta pedido o quedar como no calculable. La explicación cita los datos que ya forman parte del resultado; no vuelve a ejecutar el motor.

## Datos de demostración

El corpus de esta carpeta está marcado `SYNTHETIC`. No contiene políticas corporativas, contratos, datos personales ni documentos de proveedores reales.
